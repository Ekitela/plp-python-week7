# PLP Python Week 7 Assignment

## Shopping List Program

This assignment demonstrates Python list operations, list analysis, loops, conditions, and user interaction.

## Files

### `list_warmup.py`

Demonstrates basic list mechanics, including:

* Accessing the first and last items using indexes
* Adding items with `append()`
* Removing items with `remove()`
* Checking the number of items using `len()`

### `shopping_list.py`

A command-line shopping list program that allows the user to:

* Add an item
* Remove an item
* Show the shopping list
* Exit the program

The program also checks whether an item exists before removing it and uses `lower()` to handle user input consistently.

### `list_report.py`

Demonstrates list analysis techniques:

* Formatting list items with numbers
* Counting items based on character length
* Finding the longest item using a manual comparison pattern

## How to Run

Open Git Bash in the project folder and run:

```bash
python list_warmup.py
```

```bash
python shopping_list.py
```

```bash
python list_report.py
```
